🛠️ DevOps Pipeline & Architecture Overview

This project implements a complete modern DevOps delivery pipeline for a containerized Node.js REST application.

Stage 1
Code & Test
Node.js 24 + Express REST API
node:test + Supertest API verification
➔
Stage 2
Version Control
Git local repository
GitHub remote tracking
➔
Stage 3
Jenkins CI
Declarative Jenkinsfile
Automated test build & status validation
➔
Stage 4
Docker
Lightweight Alpine image
Port 3000 exposed with Healthcheck
➔
Stage 5
Kubernetes
Deployment with 2 Replicas
NodePort Service on port 30080

Key Verification Endpoints

  • GET /health — Application uptime, status, and health probe verification
  • GET /api/students — REST API listing all student records
  • POST /api/students — REST API creating student record
  • PUT /api/students/:id — REST API updating student record
  • DELETE /api/students/:id — REST API deleting student record
